# MyKeytool — Simulador de Java Keytool en Python

Aplicación de línea de comandos que simula las funciones esenciales de la herramienta `keytool` de Java:
generación de pares de claves RSA, almacén de claves (KeyStore) cifrado y generación de solicitudes de firma de certificado (CSR).
